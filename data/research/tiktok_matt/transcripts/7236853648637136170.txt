A customer just brought in this Lenovo laptop saying that it was an old company laptop that unfortunately went out of business, causing the system to be locked out because the domain attached to the Microsoft account was no longer in existence. So as the customer already had everything backed up, we can actually fix this by just doing a clean install window. In order to do this, I took this USB flash drive that has a Windows installation media on it and then plugged it into the laptop and then pressed the power button and then pressed the enter key to pause the startup process. With the startup process paused, I was able to press F TOV to select the proper boot device, which I wanted to be the USB flash drive on startup. Now being booted on the USB flash drive, I'm now able to reinstall Windows, and after doing that, the system is back up and working and we can now get the system back to the customer.
