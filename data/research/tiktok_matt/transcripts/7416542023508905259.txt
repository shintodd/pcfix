Windows updates can be a real pain sometimes, like in the case of this Cyberpower gaming PC that just came into my shop because after an automatic update, the system was sent to an inaccessible boot device blue screen and it couldn't even load up the recovery options or do anything it was that messed up from the update. This is likely because the boot configuration data was likely damaged in the process. Fortunately, we can still get to those recovery options by plugging in a USB installation media and selecting the repair this PC option instead of reinstalling Windows, which you typically do with the installation media. From there, we can then navigate the System Restore where there happens to be a restore point that was created right before this all went down a couple days ago. So after selecting that and waiting a while, this system is now back to booting into Windows again and we can reload that feature update that happened to fail properly this time. But before we get this system back over to our customer, it's running way too odd. Like an idol. It's sitting in the high 50s, the low sixties, which does happen when your radiator can't breathe when it's suffocating from dust. So after a quick cleaning and repasting the dried up Thermal paste, the system is now running over 20 degrees cooler and is ready for a customer to come pick up.
