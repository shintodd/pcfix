Owner of this gaming PC break their own system. See, when something sounds too good to be true, it probably is. When the owner of this PC found a guide on how to improve frame rate in games and reduce input delays by making supposed tweaks to their operating system through running a special program, it resulted in blue screens after blue screens saying that the system had a bad system configuration. And it was so bad in fact, that you couldn't even load into recovery mode because the system says that missing the BCD or boot configuration file for the actual operating system. Fortunately, the owner of this PC didn't have anything besides games loaded on the system, so we simply can plug in a USB installation media and reload Windows back onto this computer. Which once reloaded, this gaming PC is back up and functioning once again. But seriously, if you ever see one of these promises for free performance by downloading a simple app or making some kind of little tweak to your system configuration, be very cautious as there's a lot of malicious programs out there that target people searching for these particular terms.
