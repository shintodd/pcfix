This HP Omen gaming desktop has been experiencing some random crashes under any kind of multitasking workload. So let's go ahead and get the system fixed for my customer. Based on what the customer told me that they were experiencing, I figured it likely had to do with something memory related, because when the system would become unstable, it was usually during a very memory intensive task. So to go ahead and test this out, I went ahead and first started by running the Windows Memory Diagnostic tool, and after doing so, it immediately through an AIR with the memory module. So then proceeded a little deeper by running the built in HP Diagnostic tool, which you can do by hitting escape on startup and then navigating to the diagnostic utility. Once in there, I went ahead and ran the test to see that it basically instantly threw an AIR with one of the memory modules. And what's great about the HP test is it tells you exactly which damn failed, and it happens to be slot one. After pulling that out and retesting the system, it ended up working fine. However, the customer requested a brand new 32 gigabyte kit, so let's go ahead and swap out the original kit with a brand new set from crucial. And just like that, the system is back to being stable once again, both in the HP Diagnostic Utility as well as the Windows Memory Diagnostic Tool. So with that said, we Can now get this repaired gaming PC back to our customer.
