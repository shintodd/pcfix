Today I got called out for a service call because one of the businesses I do a lot of work for has this Epson Ecotank printer that's getting large streaks and poor print quality. This is a pretty common thing for tank style printers, as the tubes that carry the ink will start to clog over time, causing misprints and imperfections in the print quality. So to go and fix something like this, I went ahead and tried running the built in cleaning feature, but we couldn't because the maintenance box was full, which is actually a little plastic container that's inside of the printer. All the extra ink ends up getting dumped during the automatic cleaning features that are utilized by the printer to keep those tubes nice and clean. So after lifting up the flatbed, I was able to actually pull out the old maintenance box, and because we actually happen to have a spare on hand, I went ahead and just slap that right into place. Now this allowed me to actually run a normal cleaning, but the print quality was better, but it wasn't exactly where I wanted it. There were still some minor streaks and missing ink. So something that you can do when these printers haven't been able to print for quite a while because of a bad clog is something called the power cleaning, which is a much more powerful version of the automated cleaning feature which requires basically to sign your life Away and saying that you're willing for a bunch of ink to be lost, which will actually push a ton of ink through the print head, removing any kind of extra sediment that could have been clogging the tubes. Which after letting that run, this printer is now printing just like it's new. So we're good to go.
