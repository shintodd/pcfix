Customer just brought in this gaming PC saying the system was failing to boot, so let's get it fixed. After turning on the system to verify the issue, we were getting a screen that was stating that there was no bootable device fail. So in order to fix this, I wanted to go ahead and check the BIOS to make sure that the customer's drive was even showing up properly, which after checking it was. Only odd thing I did notice here in the BIOS was the boot order seemed to be incorrect as the Windows boot manager, which should normally be your first priority, was the last priority. So after going and reordering the boot order, I then saved and exited the BIOS and the system ended up buying right up into Windows. So it looks like the boot order was causing the issue with the system, and with this now fixed, we can now get the system back to the customer.
