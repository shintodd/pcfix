A customer just brought in this gaming PC saying that they weren't getting any display after moving it, so let's get it fixed for them. After firing up the system for the first time, we can see that the system is clearly getting stuck on the GPU LED indicator on the motherboard, which is likely an issue with the GPU. Now if you're taking a quick look at the wiring as the system was moved, I noticed that the Pcie power cable that was going into the GPU wasn't fully secured. Went ahead and actually plugged that all the way in, and after turning the system back on, we can see that it fired right up in the windows without an issue. So it looks like the system not displaying anything was a result of a loose cable. And with the system now back up and running, we can now get it back to the customer.
