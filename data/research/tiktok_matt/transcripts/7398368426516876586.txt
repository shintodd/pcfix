Windows 8 will probably go down in history to be one of the most hated versions of Windows to ever be released. This might be a hot take. I honestly don't think it was terrible, it was just bad compared to Windows 7, which prevented a lot of people from upgrading to it. And somehow all these years later, this old all in one is still stuck running Windows 8 despite the security concerns, with Microsoft cutting off support back at the beginning of 2023. So let's upgrade the system to Windows 10! And although I don't love to move old machines up to modern operating systems as they often struggle to actually keep up, but fortunately this system was actually upgraded at some point to an SSD, so it should run just fine. To install Windows 10, we can download the Upgrade Assistant via the Microsoft website and click the upgrade this PC option when prompted. This then downloads the latest version of Windows 10, which can then be installed without any of the data being lost and all the apps being carried over. This process takes about an hour or two to go and finish installing. And just like that, this system went from one of the worst operating systems ever with absolutely no updates to Windows 10, which at least will be supported for the next year.
