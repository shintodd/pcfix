Customers just brought in this gaming PC and they said that the pump LCD wasn't working correctly, so I fired up the system where I was able to see that the cooler seemed to be stuck on the IQ logo. I noticed at the time that IQ actually wasn't running on the computer in the background, so I tried manually starting up the application. After doing so, display fire right now. However, after restarting the PC, I noticed that it was back to being stuck. In order to fix this, I wanted to make sure that IQ was actually set to run on startup, as I've seen this cause issues in the past. So after opening up Task Manager and checking the startup programs, I was able to see that was actually disabled on startup. So after enabling IQ, the system was back to working as expected. I can now get the system back to the customer.
