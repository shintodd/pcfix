This HP Laptop. Blue screens on every single startup. The customer who brought the system in said that all occurred after some odd issues with their wireless connectivity after some updates. Let's dive into the system and get it fixed. First off, when a system fails to restart on a number of times, it starts to load up into what's called Windows Recovery Options. The customer said in these options they already ran Starter repair, uninstalled the latest updates, and tried repairing the system via Command Prompt and booting the safe mode, which all resulted in the exact same blue screen of death. So with all that stuff already being ran, the first thing I wanted to go ahead and check was if there was a system Restore point created on this drive before the issue even started, as issues like this are often caused by bad updates, corrupt operating systems, or a few similar issues, which all can be resolved by a system restore point. And guess what, the customer actually had one created just a few days before all this started. Five days ago. So just selecting the restore point and letting System Restore run for about an hour, the system loaded right back up in the windows without an issue. Now at this point, before I get the system back to my customer, I wanted to go ahead and verify a few things, including running all the latest updates and scanning the operating system with both HP Support Assistant as well as System File Checker to make sure everything is running nice and smooth. And as everything end up coming back perfectly clean, this laptop is now good to go and we can get it back to our customer.
